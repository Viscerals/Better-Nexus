# P1.5 change summary

- Applies all 55 approved P1.4 terminology/help groups. “EXTRA COPIES” replaces
  the main “TO SHED” list; save comparisons separately report gained/fewer wanted
  copies. Corrects unconfirmed-save, copy-window, lock/Freeze, loading, ranking,
  automation, and dependency descriptions without changing those decision rules.
- Adds a persistent seven-page Help window, available during startup, and current
  single-version installation/user documentation.
- Implements distinct Orb of Lost Memories refinement based on the supplied
  LoadoutPilot P103 MemoryMode behavior, with Nexus-specific exact-role targets,
  approved source counts, one-Orb transactions, explicit cap/recycling controls,
  exclusive action ownership and passive interrupted-operation reconciliation.
- Blocks ordinary mutations during an active/unresolved Orb operation. Starting
  Orbs explicitly disables the real session Automation owner, never silently
  restores it, and does not replace the ordinary rolling policy.
- Retains the P1.4 current-lock default and loading behavior. Existing immutable
  source tests, packages, and user data are untouched; no native execution occurs.
- First new pre-initialization UI check found that a missing StartupStatus function
  could leave Orb target controls enabled. The panel now treats missing status as
  unready. Actual spending was already guarded by the saved-state/capability path.
- New test-development corrections were explicitly fixture errors: an early-help
  test assumed StartupStatus existed before events, a mapped phrase had different
  capitalization, and six older display checks used the approved former labels.
  Those literal expectations were updated; behavioral assertions were retained.

This source archive is an imported continuation of supplied P1.4, not a claim that
its locally created Git parent reproduces the upstream repository history.
