# Support & the project

Better Nexus is an independent community continuation of Nexus for Project Ebonhold. It is not an official game or server support service.

## Development and regular support are being scaled back

The maintainer has announced that they are stepping back. This is **not a commitment to ongoing bug-fix-only maintenance**. An investigation, a fix, continued maintenance, or a timeline cannot be promised, including if a future game update breaks the addon.

Submitting a complete report helps make a problem understandable. It does not guarantee that someone will investigate or fix it. Feature requests are deferred while public prerelease stabilization is active.

## Report with enough information

Use **`/nexus report`**, provide the **exact version/build**, and explain **observed versus expected behavior**. Send report files privately through your established private conversation with the maintainer. The site has no report upload service.

Requests missing those details will not be investigated. If the tool fails, say so and include your version, the action, and any available errors or screenshots.

[Follow the troubleshooting and report guide →](guide/troubleshooting.md)

Public GitHub issue forms can hold a sanitized summary. Do not publish raw reports, saved player data, or backups. Security vulnerabilities should use the [private advisory route](https://github.com/Viscerals/Better-Nexus/security/advisories/new).
