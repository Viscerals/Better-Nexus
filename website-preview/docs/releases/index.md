## Read before updating

Replace both **Nexus** and **NexusSupport** from the same package. Keep the installed Nexus folder name and preserve the WTF folder. Start with Automation off and confirm your Wishlist assignment.

Unresolved Take pauses and cross-client LK DPS sharing remain open. The reported live Orb server-data wait is not proven resolved. The catalog/status corrections reduce repeated source work; the release does not claim a measured FPS or CPU improvement. Offline validation does not establish server action legality, actual spending, or every game-client capability.
