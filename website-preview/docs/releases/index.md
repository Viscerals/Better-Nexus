## Choose the public package deliberately

Use the versioned release asset above for the build described on this site. Public repository `main` can contain development work that is newer than a published package. Private diagnostic builds are not public release updates.

This page does not silently switch to a newer download. Check [all GitHub Releases](https://github.com/Viscerals/Better-Nexus/releases) for later packages and their exact instructions.

## Read before updating

Replace both **Nexus** and **NexusSupport** from the same package. Keep the installed Nexus folder name and preserve the WTF folder. Start with Automation off and confirm your Wishlist assignment.

The release notes include offline validation and known limitations. Offline validation does not establish live gameplay performance or every game-client capability.
